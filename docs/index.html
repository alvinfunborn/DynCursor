GOOD TO KNOW.

开始前，
你可能想知道。

一个小工具，把一件事做好。

支持哪些输入法？＋

默认面向 Windows 上的微软拼音与简体中文（0804）。可以在「光标设置」选择其他语言，或填写多个编码；第三方输入法能否正确报告状态，需要按实际环境验证。

怎么退出？强制结束后怎么恢复？＋

托盘右键选「恢复光标并退出」，或运行 DynCursor.exe --stop。如果进程被强制结束，确认已经退出后运行 DynCursor.exe --reset-cursors，或在 Windows 鼠标属性中重新应用指针方案。

从 0.2.1 升级需要注意什么？＋

先在任务管理器中结束旧版进程，再运行新版。旧版不支持新的 --stop 命令。原 YAML 配置格式保持兼容，完整变化可查看更新日志。

如何设置开机启动？＋

在设置窗口「启动与托盘」开启「登录 Windows 后自动运行」，登录时直接驻留托盘。若旧版曾手动添加启动快捷方式，请先删除重复项。

为什么切换后没有变化？＋

先检查是否已启用自动切换、选择了不同图案，且没有旧版同时运行。可用 DynCursor.exe --check-config 检查配置。窗口内修改后点「保存并应用」；Windows 方案修改后点「重新读取 Windows 图案并继续」。
