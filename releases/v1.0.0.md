## 下载与使用

下载下方 **DynCursor.zip**，完整解压后运行 `DynCursor.exe`，无需安装。此包为 **Windows x64** 版本。

首次使用请按[使用指南](https://alvinfunborn.github.io/DynCursor/#setup)设置替换光标。停止时运行 `DynCursor.exe --stop`，程序会恢复启动时的光标后退出。

## 主要更新

- 修复光标句柄使用、切回默认状态无法可靠恢复和部分失败后状态不一致的问题。

- 输入法检测增加超时，并修正本地语言输入状态判断。
- 增加单实例保护、正常退出、重置光标、配置检查和版本查询命令。
- 更新旧依赖，补充 19 项回归测试和 Windows 自动检查。
- 上线[项目主页](https://alvinfunborn.github.io/DynCursor/)与[赞助说明](https://alvinfunborn.github.io/DynCursor/sponsor.html)。收款入口暂未开放。

## 升级注意

请先退出旧版再运行新版。历史 `v0.2.1` 不支持 `--stop`，需要在任务管理器中结束旧进程；如果光标未恢复，可在旧进程结束后运行新版 `DynCursor.exe --reset-cursors`。

现有 YAML 配置格式保持兼容。来源光标保持原样，目标光标在切回默认状态时恢复启动时的图案。任务管理器强制终止进程时无法自动恢复。

`SHA256SUMS.txt` 提供下载包的 SHA-256 校验值。全部变更见[更新日志](https://github.com/alvinfunborn/DynCursor/blob/v1.0.0/CHANGELOG.md)。
