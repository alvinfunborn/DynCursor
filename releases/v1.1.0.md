# DynCursor 1.1.0

新增设置窗口与系统托盘，提供完整的 Windows 光标配置流程。

- 五个设置分组：概览、光标外观、输入与检测、启动与托盘、诊断与帮助。
- 直接选择静态 `.cur` 文件与预览；三类光标分别启用，保留高级 Windows 来源映射。
- 附带三枚原创绿色光标，默认直接使用，首次无需修改 Windows 来源指针。
- 托盘打开设置、暂停／恢复、Windows 指针设置、重新捕获、恢复并退出；重复启动唤出已有窗口。
- 登录自启动、手动启动隐藏、关闭窗口保留托盘；检测间隔、状态稳定时间和诊断日志可配置。
- 重新设计 Logo，统一应用、托盘、窗口和网页标志。
- 完善 MIT License、第三方组件许可证与素材范围；便携包不包含授权尚未核实的历史光标。
- Pages 增加设置窗口指南，以及沿用 README 九张截图的 Windows 详细操作、恢复与排错。

需要 **Windows 10 / 11 x64** 与 **Microsoft Edge WebView2 Runtime**。下载 `DynCursor.zip` 后完整解压到可写目录；保留 `config`、`resources` 和许可证文件。无需管理员权限，不会自动开启登录自启。

升级前先退出旧版本。0.2.1 需要在任务管理器退出；1.0.0 可用 `--stop`。旧 YAML 配置继续兼容。手动复制旧配置后，直接光标文件可在设置窗口选择；修改系统方案前先暂停，应用后重新捕获。旧启动快捷方式请与新自启开关择一使用。

正常退出会恢复捕获的光标；强制结束无法自动恢复。`--reset-cursors` 重新加载 Windows 已保存方案，并非恢复出厂设置。
