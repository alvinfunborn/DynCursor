# DynCursor 1.1.1

设置窗口按 README 的理解顺序重新整理。

- 主页面按“选输入法语言 → 选图案 → 保存并试一试”引导，常用语言无需填写编码。
- 支持一键选用内置绿色光标，按箭头、I 形、链接小手分别配置并预览替换图案。
- 将“直接选文件”和“按 README 设置 Windows”两种操作分开讲解；已有 Windows 方案继续保留，不会因切换说明页而改变配置。
- 菜单收为“光标设置 / 启动与托盘 / 更多设置”；映射 ID、检测参数、日志、配置等高级项目默认折叠。
- 可打开记事本验证效果；有未保存更改时先提示保存。托盘中的“重新捕获”改为“重新读取 Windows 图案并继续”。

保留 1.1.0 的全部功能和配置格式。升级前正常退出旧进程，完整解压覆盖；已有配置可保留。需要 Windows 10 / 11 x64 和 Microsoft Edge WebView2 Runtime。
