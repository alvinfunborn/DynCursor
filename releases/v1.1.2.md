# DynCursor v1.1.2

修复登录 Windows 后设置窗口意外弹出的问题。

- `--background` 发现已有实例时静默退出，不再触发“打开设置”。
- 手动双击程序仍可打开已有设置窗口；`--show` 首次启动也会显示窗口。
- 更新 README 和 Pages 的自启动指南及排查说明。

旧版手工放到 `shell:startup` 的快捷方式，请在目标路径后添加 ` --background`（加在引号外），例如 `"D:\apps\DynCursor\DynCursor.exe" --background`。推荐仅保留程序内的登录自启动，避免重复入口。

升级前退出旧进程，解压后保留原 `config` 目录。原有光标及托盘设置继续兼容。
