常用入口

首次使用

到“光标外观”直接选择自定义 .cur 文件；也可按图文指南配置 Windows 来源指针。设置文件在程序目录，请把整个文件夹放在可写的固定位置。

选择需要变化的光标

自定义状态生效时替换，其他状态恢复本次捕获的原始光标。

高级：完整光标映射

格式为“目标 ID:来源 ID”，用逗号分隔。上面的三项会同步到这里；其他自定义映射会保留。至少保留一项，全部停用请关闭“启用自动切换”。

在 Windows 里修改光标后

通过下方入口会先暂停切换。完成系统设置并点“应用”后，再点“重新捕获并恢复运行”。直接选择的文件优先于 Windows 来源指针。

识别你的输入状态

对配置语言中的非拉丁输入模式显示自定义光标。

四位十六进制语言 ID，用逗号分隔。默认 0804 为简体中文；例如繁体中文（台湾）0404、日语 0411。语言匹配后，还会检查输入法是否处于非拉丁输入模式。

部分输入法或受保护窗口不提供状态，检测不可用时会保留当前状态，可手动暂停恢复原始光标。

默认 100；越小响应越快，后台唤醒也更频繁。范围 50–2000。

默认 100；状态持续达到该时间才切换，减少快速切换窗口时的闪动。0 表示不等待。

按你的习惯运行

自启动立即生效，其余选项点“保存并应用”后生效。

写入当前用户的登录启动项，无需管理员权限。登录时直接驻留托盘。移动程序文件夹后请关闭再重新开启。

双击程序后直接驻留托盘。点击托盘图标或再次打开程序即可显示设置窗口。

关闭按钮只隐藏窗口，后台继续工作。取消后，关闭窗口会恢复光标并退出。

托盘操作

左键点击图标打开设置；右键可暂停／恢复、打开 Windows 指针设置、重新捕获光标或退出。如果任务栏没有显示图标，检查系统托盘的折叠区域。

如果之前手动创建过“启动”文件夹快捷方式，请删除重复项后再启用这里的自启动。

配置、恢复与帮助

运行中的变更都发生在本机。

默认关闭。启用后记录状态与错误，不记录键入内容；保存后生效。

正在读取…

可手动修改 YAML，再重新读取。窗口保存会保留未知字段，但会重新排版配置文件。

光标恢复

暂停会恢复本次运行捕获的光标。异常退出导致光标未恢复时，可重载 Windows 已保存的指针方案；这与恢复 Windows 出厂方案不同。
